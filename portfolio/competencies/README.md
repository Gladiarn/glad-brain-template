# Craft Areas

This folder holds one note per craft area you want to grow and show evidence for, such as accessibility, front-end performance, design systems, or typography. The folder keeps its upstream name, `competencies`, so the vault tooling still recognises it.

## How it works

1. **Create** a craft note using the `Competency Note` template
2. **Link** work notes to craft areas in their `## Related` section
3. **Evidence accumulates via backlinks** -- open any craft note and check the backlinks panel to see all work that demonstrates it
4. **Portfolio** aggregates evidence per quarter in `Craft Evidence` sections

## Frontmatter fields

- `current-level` -- where you assess yourself for this craft area
- `target-level` -- where you're aiming next

## Tips

- Don't maintain evidence lists manually in craft notes -- let backlinks do the work
- Use annotations when linking: `[[Craft Name]] -- what was demonstrated`
- Review craft backlinks when updating your portfolio or writing a case study
